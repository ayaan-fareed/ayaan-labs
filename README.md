# Ayaan Labs — immersive portfolio starter

The supplied archive contained only `package-lock.json` and no application source. This starter therefore creates the requested experience from scratch rather than replacing an existing architecture.

Stack: Next.js, React, TypeScript, Three.js, GSAP, Lenis.

Run:
```bash
npm install
npm run dev
```

The 3D scene is procedural/custom and does not use David Heckhoff's assets or source code. Project content is data-driven in `data/projects.ts`.
